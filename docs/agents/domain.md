# Domain Docs

采用 single-context。网页、API、共享契约及车端共用一套项目术语和架构决定。

## 阅读规则

- 探索相关代码前，读取根目录 GLOSSARY.md，以及 docs/adr/ 中与当前范围相关的记录。
- 文件尚不存在时继续工作，无需为目录完整性创建空文档。
- 术语明确后按需写入词汇表；词汇表只记录领域定义，不存放实现细节或任务清单。
- 架构决定在需要记录真实取舍时按需创建；本轮不预填架构决定。
- 规格、任务、代码审阅和交接使用词汇表中的同一名称；发现现有架构决定与新方案冲突时明确说明。

## 布局

全项目词汇表：GLOSSARY.md。
架构决定：docs/adr/。
当前不设置 GLOSSARY-MAP.md 或分模块词汇表。
