# Triage Labels

| 技能中的状态 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者判断如何处理 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 需求及边界已明确，可交给 agent 实施 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 不处理 |

技能引用状态时使用表中对应标签。保留已有其他标签；状态变化时移除已不适用的状态标签。
ready-for-agent 不扩大任务的执行授权，不解除项目的多 agent、实车或公开数据限制。
