## 本轮软件收尾

- InstrumentEvidencePage 的资产、观测、站点清单完成分页；ObservationReview 支持候选生成、确认/拒绝、最新决定展示、追加写入和 expected_review_id 并发检查。
- 可配置 viewer/reviewer/operator 独立身份，原共享密钥/本机模式保留。认证主体参与业务与 HTTP 写入审计。
- packages/contracts/openapi.yaml 从实际应用路由生成；脚本仅生成文档，不打开数据库、不启动工作者。
- Docker 不复制运行归档/数据库，冻结依赖安装；独立凭据使用只读挂载。

## 尚不能完成的输入与验证

1. 相机内参/外参、标记实际尺寸及其误差、注册场景对齐和速度边界；不能用示例数值代替。
2. 现场 ROS/Jetson ARM64 依赖和硬件；Windows x86 构建不是 Jetson 部署产物。
3. PTP、停稳、完整路线、暗光/小字、30 分钟采集、断电恢复与误差预算现场复核。
4. 客户数据库、业务字段关系、通道单位、有效期和阈值；在用户给定的挑战杯目录内未找到 .bak/.sql/.sqlite/.db/.mdb 数据库交接文件。未搜索无关私人目录，未声称完成数据库恢复或映射。
5. 通用无标记模型训练素材；当前是明确标记代理流程。
6. 全部单元、集成、E2E、性能、故障注入、权限与实车测试均依用户要求未执行。

这些是准确的输入/验证边界，不是待用户批准的代码修改。其余任务书范围的软件流程已形成开发候选；后续应从实际验证结果修复，而不是重复恢复源码或重建系统。
